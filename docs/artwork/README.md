# Illustrated manual artwork

These assets were created with the built-in ImageGen tool for the Dune user manual. They are thematic illustrations, not Minecraft screenshots or additional in-game item models. The final PDF embeds the art and 64 reference icons; the game resource-pack skin is a separate asset documented in `DuneResourcePack/SANDWORM-TEXTURE.md`.

## Cover prompt

Use case: illustration-story. Asset type: portrait book-cover artwork for a polished Project Dune Minecraft user manual. Create a sophisticated cinematic editorial illustration of Arrakis at golden hour: sweeping immense ochre dunes, dark basalt rocky terraces with three visible flat levels, a small cloaked Fremen explorer foreground, distant cave sietch entrance. A huge blocky quadrupedal Minecraft Sniffer is the sandworm silhouette emerging from dust in the middle distance: broad rectangular body, six stubby blocky legs, large rectangular head and low snout, desert-tan segmented skin, subtle ivory tooth-like edges; it must unmistakably have the Sniffer shape, not a humanoid zombie. Stylized Minecraft-inspired block geometry blended with premium painted concept-art shading. Warm antique gold, sand, terracotta and deep charcoal. Portrait 2:3 aspect, exceptionally sharp detailed art. Upper third mostly deep charcoal atmospheric sky and negative space for separately overlaid book typography; no lettering or logo anywhere. Lower two thirds rich dunes, giant Sniffer, a tiny traveler for scale. No photoreal people, no modern firearms, no interface, no pasted captions, no watermarks. High-end collectible field-guide cover, dramatic restrained lighting.
