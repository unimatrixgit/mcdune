# Tonight's Hetzner deployment runbook

> Historical plan, superseded for the live lobby on 18 October 2026. See [the verified live deployment](live-lobby/README.md): Velocity and Paper lobby share the EU Minecraft VM; CloudPanel and the website run on a separate host. Do not install CloudPanel or Pterodactyl over the live Minecraft VM. The saved Guild lobby is implemented and deployed from the beta branch. The five planet backends remain pending; the seven-VM layout below is a proposal, not existing infrastructure.

## Provisioning prerequisites
Create Debian VMs in Hetzner Cloud, attach all seven to a Hetzner private network,
install your SSH public key, and record private IPs. Choose VM RAM/CPU based on
expected players; lobby VM needs headroom for website, database, panel and Paper.
Do not paste API tokens, passwords or SSH private keys into chat or Git.

## One-time network config
Copy `network/network.example.json` to `network/network.json` locally and
fill in the private IPs and SSH hosts. Never commit personal infrastructure
details or the forwarding secret. Run
`python3 network/apply-network.py network/network.json --output network/generated`
to render settings. The `--deploy` mode requires SSH key access and correctly
installed services; test on staging before using it.

## World files
`network/generate-world-files.py` generates a complete per-world config folder
and zip for each world, based on the DuneTerrain source configuration.
These are **world-generation configuration files**, not pre-generated Minecraft
region (.mca) files. Actual playable worlds must be generated by starting each
Paper backend with the correct compatible generator installed. Spacing Guild
custom lobby generator is not implemented; do not advertise it as ready.
World generation should be tested with a fresh world directory first.

## Installation order
1. On lobby VM: CloudPanel first, then Java 21, then Pterodactyl panel and Wings.
2. On all other VMs: Java 21 and Wings prerequisites.
3. Register each VM as a Pterodactyl node and configure Wings from panel-issued credentials.
4. Install Paper 1.21.4 and Velocity via supported Pterodactyl eggs.
5. Upload the compiled Dune plugins and planet-specific generator config.
6. Configure Velocity modern forwarding and identical secret across Paper nodes.
7. Configure CloudPanel site + HTTPS and a separate secured panel domain.
8. Start each server, inspect logs, test teleport, and verify only Velocity
   is reachable publicly. Do not run systemd Minecraft units alongside Wings.

## Known gaps
No Hetzner VM has been created by these scripts. No pre-generated Minecraft world
data exists. Pterodactyl is not installed remotely. The generator's support for
Spacing Guild and the full network package still require verification.
